# Sione Uhlig – Portfolio

My personal portfolio site built with Next.js (App Router), TypeScript and Tailwind CSS for WDD 430.

## 🔗 Live Site

**https://wdd430-portfolio-sepia.vercel.app/**

- Home: https://wdd430-portfolio-sepia.vercel.app/
- About: https://wdd430-portfolio-sepia.vercel.app/about
- API: https://wdd430-portfolio-sepia.vercel.app/api/hello

## Project Structure

- `app/layout.tsx` – root layout with Header and Footer
- `app/page.tsx` – home page with project list
- `app/about/page.tsx` – about page with skills
- `app/api/hello/route.ts` – simple API route returning JSON
- `components/` – Header, Footer, ProjectCard, ProjectList, SkillCard (custom component)

## Run Locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
